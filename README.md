# Pervoskites_Prediction-
The accelerating demand for next-generation electronic, photovoltaic, and optoelectronic 
materials has placed renewed focus on high-throughput prediction of material properties. In 
this project, we present a machine learning-based workflow aimed at predicting the band gap 
of oxide perovskite compounds — a property that directly influences their electrical 
conductivity and suitability for various applications. Our methodology involves a two-stage 
pipeline. In the first stage, a classifier is trained to distinguish between wide band gap (≥ 0.5 
eV) and narrow/metallic perovskites using a rich set of elemental and geometric descriptors. 
In the second stage, a regression model is trained exclusively on the wide band gap subset to 
predict the exact band gap values with high accuracy. These trained models are then applied 
to a dataset of 462,248 formable and stable candidate perovskite structures, enabling the 
identification of promising new materials with desirable band gap properties. The project not 
only demonstrates the application of supervised learning to materials informatics but also lays 
the foundation for a scalable and efficient computational pipeline capable of screening large 
material spaces. The results support the growing integration of Big Data and Machine 
Learning tools in materials science, where automated, data-driven discovery platforms are 
essential to keep pace with the expanding chemical and structural search spaces.
